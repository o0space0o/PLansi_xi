# Add your music here

Place audio files directly in this folder. Songs are **kept local and excluded from Git**; the GitHub repository contains no audio tracks. Subfolders are not scanned.

Supported filename extensions: `.mp3`, `.wav`, `.ogg`, `.opus`, `.m4a`, `.aac`, and `.flac`. Browser codec support still applies. A track named `Words before sleep` is prioritized when present; other songs sort by filename, including numeric order.

Start PLansi_xi, press **M** or middle-click to enter music mode, then short-left-click to play. The wheel adjusts volume. Short-right-click stops; holding left/right for 650 ms selects the next/previous track. Middle-click again exits while playback continues.

After adding music, exit and re-enter music mode to refresh the playlist. An empty folder simply leaves music unavailable until you add a track; the orbital explorer works normally.
